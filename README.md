# Mouse_Strain_Checker
Mouse_Strain_Checkerは、公開マウスRNA-seqのSRX番号を入力することで、染色体別・ゲノム区間別に系統候補を推定する研究用ツールです。データ取得からHISAT2によるマッピング、既知SNPパネルとの照合までを自動化し、候補系統、使用SNP数、候補間のスコア差をCSV・HTMLで出力します。単一系統と2系統モデルを比較し、情報不足や区間間で結果が一致しない場合は判定を保留します。Dockerとブラウザ操作に対応し、既存BAMも再利用可能です。RNAで観測できた領域に基づく暫定推定であり、DNA上の系統や交雑率を確定するものではありません。現在は試作版です。
